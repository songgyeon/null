# 안 쓰는 아이콘 후보

지금 쓰는 건 `../icon.png` / `../adaptive-icon.png` / `../adaptive-bg.png` 다.
아래는 만들어만 두고 안 쓰는 것들 — 바꾸고 싶으면 `../icon.png`에 덮어쓰면 된다.
전부 1024×1024, 앱 팔레트(#5d5490 · #ff7fae · 라벤더→핑크) 그대로다.

| 파일 | 무엇 |
|---|---|
| `blank-cursor.png` | 점선 빈칸 + 커서. 등록 화면의 □□을 그대로 올린 것 |
| `null-stacked.png` | NULL을 두 줄로 접은 것. 한 줄로 쓰면 홈 화면 크기에서 획이 뭉갠다 |
| `bubble.png` | 말풍선 + 커서 + 말줄임. 한눈에 메신저인 걸 알린다 |

안드로이드는 아이콘을 동그랗게 잘라낸다(가운데 66.7%만 보인다). 셋 다 그
안쪽에 들어오게 그렸다 — 새로 만들 때도 가장자리에 뭘 두면 안 된다.
