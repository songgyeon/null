# 안 쓰는 아이콘 후보

지금 쓰는 건 `../icon.png` / `../adaptive-icon.png` / `../adaptive-bg.png` 다.
아래는 만들어만 두고 안 쓰는 것들 — 바꾸고 싶으면 `../icon.png`에 덮어쓰면 된다.

| 파일 | 무엇 |
|---|---|
| `null-a.png` | 지금 아이콘의 이전 판. 글자가 왼쪽으로 50px 밀려 있다 |
| `null-b.png` | Y2K 창. NULL이 대화상자 안에 들어 있다 |
| `null-c.png` | CD. 어두운 배경에 홀로그램 |

안드로이드는 아이콘을 동그랗게 잘라낸다 — 가운데 66.7%만 보이고 나머지는
버린다. 새로 만들 때 가장자리에 뭘 두면 안 된다.

그리고 가운데는 **흰 글자 기준**으로 맞춘다. 글자에 오른쪽 아래로 빠지는
그림자가 붙어 있어서, 그림자까지 포함해 가운데를 잡으면 눈에 보이는 글자가
그림자 폭만큼 왼쪽으로 밀린다. 한 번 그렇게 나갔다.
