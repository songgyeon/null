# Galmuri11

앱 화면 전체가 이 글꼴로 그려진다. 없으면 번들이 이 자리에서 멈춘다.

- 판: Galmuri v2.40.3
- 만든 사람: Lee Minseo (quiple@quiple.dev)
- 라이선스: SIL Open Font License 1.1 — `OFL.txt`

OFL은 재배포를 허용하되 라이선스 전문을 같이 두라고 요구한다. 그래서
`OFL.txt`가 여기 같이 있다. 글꼴 파일만 옮기지 말 것.

## 왜 5MB짜리 외곽선 판을 쓰나

같은 배포판에 `Galmuri11Bitmap-Regular`(0.75MB)가 있다. 픽셀 글꼴이라
비트맵 판이 원래 의도한 렌더링이고 7분의 1 크기다.

그런데 이 앱은 9px부터 16px까지 여러 크기로 글자를 그린다. 비트맵 판은
설계 크기(11px)를 벗어나면 뭉개지거나 대체 글꼴로 떨어진다. 그래서
외곽선 판을 쓴다. APK 용량이 급하면 그때 실제 화면을 보고 바꿀 것.
