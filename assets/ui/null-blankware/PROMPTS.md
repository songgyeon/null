# Generation prompt set

Mode: built-in raster ImageGen, one isolated PNG per asset.

## Shared style prompt

Bright dreamy `NULL BLANKWARE`: Korean Y2K retro-computer stationery, milky white body, blush-pink/ice-blue/soft-lilac opal fill, thin deep-grape pixel-stepped outline, crisp planar construction, small upper-left highlights and short lower-right hard shadow. Show a conceptual transition from blank/transparent to gently filled. No baked text, no dark navy surface, no generic glass card, no photoreal toy plastic.
