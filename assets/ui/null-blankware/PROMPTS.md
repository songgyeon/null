# Generation prompt set

Mode: built-in raster ImageGen, one isolated PNG per asset.

## Shared style prompt

Bright dreamy `NULL BLANKWARE`: Korean Y2K retro-computer stationery, milky white body, blush-pink/ice-blue/soft-lilac opal fill, thin deep-grape pixel-stepped outline, crisp planar construction, small upper-left highlights and short lower-right hard shadow. Show a conceptual transition from blank/transparent to gently filled. No baked text, no dark navy surface, no generic glass card, no photoreal toy plastic.

- **Auxiliary windows:** three restrained blank companion assets. The lilac error dialog carries one tiny sparkle, the pink system-error dialog one hollow heart, and the blue-to-pink loading strip relies almost entirely on frame depth and an empty continuous progress groove. - **Backgrounds:** quiet center, decorative edge-only grid/bubbles/sparkles/CD; one 16:9 desktop and one 9:16 mobile composition.
- **CTA:** wide blank pink-to-ice candy button with a small heart at the far right; transparent outside.
- **Stickers:** separate missing-sector opal CD, partial-fill heart, four-point sparkle, translucent opal bubble, and horizontal null-cursor decal.
- **Icons:** six separate square icons for rooms, map, camera, hidden, bag, and gift; silhouette-first, consistent deep-grape outline, one opal highlight, no labels.
- **Gift/wrap panel:** tall quiet wrapping-station shell with one slim left ribbon rail, one bow and faint section grooves; center remains blank for dynamic content.
- **Gift reason note:** wide creamy stationery card with one short ribbon tab, one tiny empty-heart seal and a central recessed blank slot; sentence fragments remain HTML on the clean left/right margins.

Reference family: the supplied retro-window, pastel UI, pixel-game and current NULL screenshots. Dynamic copy remains HTML.
