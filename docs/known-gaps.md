# 알려진 미완성과 기록 — 범위 명세

이 문서는 「없는 것을 없다」고 적는 자리다. 코드로 억지로 메우지 않고,
완성된 척하지 않기 위해 남긴다.

## Expo(Android 앱) — 알려진 미완성 기능

이번 정상화·모델 비교·테스터 판의 기준은 **웹**이다. Expo는 완성판이
아니며, 테스터 배포 대상이 아니다. 아래는 웹에는 있고 앱에는 없는 것들이다.

| 기능 | 웹 | Expo | 비고 |
|---|---|---|---|
| D-0 (디데이 선택) | 있음 | **없음** | `askDday`류 UI·`markScene("…","dday_choice")` 예약이 앱에 없다 |
| WHO (상대 선택 화면) | 있음 | **없음** | `pickWho`에 해당하는 화면이 없다. App.tsx의 「WHO GETS THIS」는 선물 수신자 선택일 뿐 상대 선택이 아니다 |
| partner 선택 저장 | 있음 | **없음** | `savePartner`를 import만 하고(App.tsx) 호출하는 곳이 없다 |
| partner_confirm·partner_known 장면 예약 | 있음 | **없음** | 위 UI가 없으므로 예약 자체가 생성되지 않는다 |

관전 사건 호출의 `gifts` 동봉(§8.5의 재료)은 **앱에 원래 있었고**(app/lib/api.ts
`genAuto`의 `gifts: await loadGifts()`), 웹의 관전 사건 fetch에는 빠져 있던 것을
이번에 추가했다 — 발견 장면의 재료는 이제 양쪽 다 실린다.

웹·Expo가 **공통으로 고쳐진 것**(선물 기억, give 수령, 시계, 워커 단일
텍스트 감지)은 이 표에 없다 — 그것들은 양쪽 다 있다.

Expo에 위 기능을 붙이는 것은 이번 범위 밖이다. 붙일 때는 웹과 같은
예약·ack 계약(peekScene/ackScene, 관전 사건 큐)을 그대로 쓴다 — 병렬
계약을 새로 만들지 않는다.

## 커밋 메시지의 모델 식별자 — 과거 위반 기록

규칙: 모델 식별자는 실행에 필요한 설정(worker.js의 MODELS·ENGINE 표)에만
남기고, 커밋 메시지·README·docs 산문·일반 주석에는 넣지 않는다(역할명으로
쓴다).

이미 푸시된 커밋 메시지가 이 규칙을 어겼다. git history를 다시 쓰지
않으므로 **변경 불가능한 과거 위반**으로 여기 기록하고, 이후 커밋부터
금지를 적용한다. 전수 조사 기준(자동 트레일러 제외, 제목·본문 산문):
**14건** —

- 제목까지 어긴 것: `e84137f`(G2) · `02776ca`(G3) · `8719451`(G4)
- 본문 산문에서 어긴 것: `3cc520d` · `69562e6` · `18c5e88` · `b6f1844`
  · `3bb11e9` · `ed007c7` · `e65de79` · `ce7ace5` · `01f30c3` · `ae3b23e`
  · `13e5954`

추적 파일(README·docs·주석) 안의 모델 식별자는 역할명(저비용 Writer ·
일반 Director · 상위 Finalizer · single 비교 Writer)으로 바꿨다. 예외는
worker.js의 MODELS·ENGINE 설정값 — 실행에 필요한 allowlist다. 테스트가
정확한 ID를 봐야 할 때는 이 설정을 import해서 비교하고, 문자열을 다시
적지 않는다.
