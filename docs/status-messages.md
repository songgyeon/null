# 상태메시지

예쁜 문구를 여러 개 돌려 쓰지 않는다. 관계가 나아간 만큼만 미묘하게 바뀐다.

두 사람 다 대놓고 상대를 지칭하지 않는다. 평범한 공지처럼 써놓고 실제로는
한 사람만 알아듣게 한다. 그래서 같은 시기의 둘을 나란히 놓으면 주고받는
말이 된다 — 정작 둘은 서로 보라고 쓴 게 아닌데.

지금 쓰는 것은 아래 표에서 다섯 쌍만 뽑은 것이다. 나머지는 버린 게 아니라
아직 안 쓴 것이다. 서버가 `status_<char>`를 내려주면 클라이언트의 기본
문구를 이기므로, 모델이 그날의 상메를 직접 고르게 할 자리가 이미 있다.

## 지금 쓰는 다섯 쌍

`worker.js`의 `STATUS`, `index.html`의 `PROFILES`, `app/lib/profiles.ts`의
`PROFILES` — 셋이 같아야 한다. 어긋나면 API를 켰을 때만 문구가 달라진다.

| 대화 | 이재언 | 이민현 |
|---|---|---|
| 0 | 별일 없어요. | 수업 중. 아마도. |
| 16 | 문은 열어둘게요. | 기다리는 거 아니에요. |
| 40 | 어디 안 가요. | 그 말 취소하면 안 돼요. |
| 80 | 아직 남았어요. | 곧이잖아요. 지금이 아니라. |
| 120 | 잘 지내요. 항상. | 모르는 걸로 할게요. |

재언 단독으로는 `문은 열어둘게요.`, 민현 단독으로는 `기다리는 거 아니에요.`가
제일 그 사람답다. 한 세트로 읽을 때는 `아직 남았어요. / 곧이잖아요. 지금이
아니라.`가 제일 세다.

## 전체 후보

### 1단계 · 아직 별 감정 없어 보일 때

| 이재언 | 이민현 |
|---|---|
| 보건실에 있어요. | 수업 중. 아마도. |
| 급한 일은 전화. | 보건실에 있어요. |
| 별일 없어요. | 이어폰 찾는 중. |
| 오늘도 평소처럼. | 오늘도 재미없게. |
| 답장은 늦을 수 있어요. | 자는 거 아니에요. |

### 2단계 · 유저를 기다리기 시작할 때

| 이재언 | 이민현 |
|---|---|
| 문은 열려 있어요. | 기다리는 거 아니에요. |
| 늦으면 연락해요. | 답장 빠른 편. |
| 들어갈 때 말해요. | 오면 말해요. |
| 오늘은 조금 늦네요. | 먼저 연락해도 되고. |
| 아픈 데 없어도 와요. | 자리 하나 비어 있어요. |

### 3단계 · 호감은 있는데 인정하지 않을 때

| 이재언 | 이민현 |
|---|---|
| 기다리는 건 아니고. | 왜겠어요. |
| 커피가 하나 남았어요. | 그냥 알아두려고요. |
| 필요한 동안은. | 신경 쓰이는 건 맞고. |
| 문은 열어둘게요. | 제가 먼저 본 거예요. |
| 안 오는 것보단 낫고. | 안 기다렸어요. 조금밖에. |

### 4단계 · 둘 다 서로를 의식할 때

| 이재언 | 이민현 |
|---|---|
| 말하고 싶어지면 해요. | 몇 번 물어도 같아요. |
| 어디 안 가요. | 먼저 잊지 마요. |
| 답은 같아요. | 오래 지나고 확인해요. |
| 잊을 것 같아요? | 그 말 취소하면 안 돼요. |
| 여기 있을게요. | 누군지 알아보려고? |

### 5단계 · 떠날 날이 가까워졌을 때

| 이재언 | 이민현 |
|---|---|
| 아직 남았어요. | 곧이잖아요. 지금이 아니라. |
| 평소처럼 해요. | 세고 있는 건 아니고. |
| 시간은 안 봤어요. | 오늘까지는 평소처럼. |
| 필요한 건 미리 챙겨요. | 안 알려줘도 알아요. |
| 남은 동안은 여기 있어요. | 아직 일주일. |

### 6단계 · 떠난 뒤

| 이재언 | 이민현 |
|---|---|
| 잘 지내요. 항상. | 모르는 걸로 할게요. |
| 문은 그대로 열려 있어요. | 자리 그대로 뒀어요. |
| 연락 오면 답해요. | 잊었으면 다시 기억하게 할게요. |
| 잊기엔 기억나는 게 많아서. | 나중이 언제인데요. |
| 가끔 생각나요. | 다시 오면 돼요. |

### 7단계 · 다시 만난 뒤

| 이재언 | 이민현 |
|---|---|
| 잘 왔어요. | 이제 와요? |
| 이번에는 천천히. | 안 잊었네요. |
| 아직 자리 있어요. | 이번에는 안 가요? |
| 생각보다 오래 걸렸네요. | 자리 그대로예요. |
| 답은 그대로예요. | 확인 끝났어요. |

## 맞물리는 조합

단계가 아니라 짝으로 읽히는 것들. 같은 시기에 걸어두면 둘이 대화가 된다.

| 이재언 | 이민현 |
|---|---|
| 급한 일은 전화. | 안 급해도 전화. |
| 문은 열려 있어요. | 아픈 데 없어도. |
| 들어갈 때 말해요. | 확인했어요. |
| 답장은 늦을 수 있어요. | 그래도 먼저 할게요. |
| 커피가 하나 남았어요. | 누구 주려고. |
| 조용한 하루. | 제가 없어서요? |
| 기다리는 건 아니고. | 저도요. 조금밖에. |
| 아직 남았어요. | 곧이잖아요. 지금이 아니라. |
| 잘 지내요. 항상. | 모르는 걸로 할게요. |
| 문은 그대로예요. | 자리도 그대로예요. |
| 잊을 것 같아요? | 확인은 나중에 해요. |
| 어디 안 가요. | 그 말 취소하면 안 돼요. |

## 노래 제목으로 맞추는 짝

재언 — Should Have Known Better.
민현 — Don't Delete the Kisses.

둘의 선곡이 그대로 이어진다. 재언은 뒤늦게 알아차리는 쪽이고, 민현은 지우지
말라고 붙잡는 쪽이다.
