# 상태메시지

예쁜 문구를 여러 개 돌려 쓰지 않는다. 관계가 나아간 만큼만 미묘하게 바뀐다.

두 사람 다 대놓고 상대를 지칭하지 않는다. 평범한 공지처럼 써놓고 실제로는
한 사람만 알아듣게 한다. 그래서 같은 시기의 둘을 나란히 놓으면 주고받는
말이 된다 — 정작 둘은 서로 보라고 쓴 게 아닌데.

지금 쓰는 것은 아래 표에서 일곱 쌍만 뽑은 것이다. 나머지는 버린 게 아니라
아직 안 쓴 것이다.

**서버는 상메를 안 보낸다.** 전에는 워커가 같은 표를 다시 계산해 응답에
실었고 앱이 그걸 저장해 기본값보다 우선했는데, 오가는 게 늘 제 값의
메아리였다 — 아무 일도 안 하면서, 한 번 저장되면 앱을 새로 빌드해도 옛
문구가 새 기본값을 이기는 길만 냈다. 걷어냈다.

모델이 그날의 상메를 직접 쓰게 하는 건 지금 안 한다. 열두 줄이 짝으로
맞물리는 게 이 기능의 전부인데 한쪽만 모델이 바꾸면 그 순간 대화가 아니라
그냥 두 문장이 된다. 나중에 한다면 그때 별도 필드로 새로 계약한다.

## 지금 쓰는 다섯 쌍

`index.html`의 `PROFILES`와 `app/lib/profiles.ts`의 `PROFILES` — 둘이 같아야
한다. 어긋나면 웹과 앱이 다른 문구를 쓴다.

| 대화 | 이재언 | 이강현 |
|---|---|---|
| 0 | 별일 없어요. | 수업 중. 아마도. |
| 16 | 문은 열어둘게요. | 기다리는 거 아니에요. |
| 40 | 어디 안 가요. | 그 말 취소하면 안 돼요. |
| 80 | 아직 남았어요. | 곧이잖아요. 지금이 아니라. |
| 120 | 남은 동안은 여기 있어요. | 안 알려줘도 알아요. |
| **D-0 · 안 왔다** | **잘 지내요. 항상.** | **모르는 걸로 할게요.** |
| **D-0 · 다시 왔다** | **아직 자리 있어요.** | **이제 와요?** |

마지막 두 쌍만 대화 수가 아니라 **시계**가 정한다. 실습이 끝나는 건 몇 마디
했느냐와 상관없는 일이라서다. 대화 수(120)에 걸어놨더니 하루에 백스무 마디
하면 D-29에 작별 인사가 떴다.

그런데 D-0에서 멈춰만 두니 더 이상했다. 서른한 날째에도, 백 일째에도
「잘 지내요. 항상.」을 걸어놓고 유저와 계속 대화하는 화면이 된다. **작별
인사를 붙여둔 사람과 무한히 이야기하는 셈이다.**

그래서 떠난 뒤를 둘로 나눈다. 기준은 D-0 뒤에 **유저가** 말을 했느냐다.
안 했으면 아직 떠나 있는 것이고, 했으면 다시 온 것이다. 유저 발화만 센다 —
강현이 선톡만 보내고 유저가 답을 안 한 건 다시 온 게 아니다.

새로 저장할 상태가 없다. 이미 갖고 있는 타임스탬프로 판정되고, 말을 거는
순간 저절로 넘어간다. 프로필만 열면 작별 인사고, 한 마디 하면 재회다.

재언 단독으로는 `문은 열어둘게요.`, 강현 단독으로는 `기다리는 거 아니에요.`가
제일 그 사람답다. 한 세트로 읽을 때는 `아직 남았어요. / 곧이잖아요. 지금이
아니라.`가 제일 세다.

## 맞물리는 조합

단계가 아니라 짝으로 읽히는 것들. 같은 시기에 걸어두면 둘이 대화가 된다.

| 이재언 | 이강현 |
|---|---|
| 급한 일은 전화. | 안 급해도 전화. |
| 문은 열려 있어요. | 아픈 데 없어도. |
| 들어갈 때 말해요. | 확인했어요. |
| 답장은 늦을 수 있어요. | 그래도 먼저 할게요. |
| 커피가 하나 남았어요. | 누구 주려고. |
| 조용한 하루. | 제가 없어서요? |
| 기다리는 건 아니고. | 저도요. 조금밖에. |
| 아직 남았어요. | 곧이잖아요. 지금이 아니라. |
| 잘 지내요. 항상. | 모르는 걸로 할게요. |
| 문은 그대로예요. | 자리도 그대로예요. |
| 잊을 것 같아요? | 확인은 나중에 해요. |
| 어디 안 가요. | 그 말 취소하면 안 돼요. |
