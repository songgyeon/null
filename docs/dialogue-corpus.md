# 재언·민현 대화 데모 통합 문구집

> 완성본 · 1차~6차 통합  
> 기준: 일상 70% · 은근한 호감 25% · 직접적인 설렘 5%

## 사용 규칙

- `Q.` 뒤의 `/` 구분 문구는 같은 의도로 묶는 입력 별칭이다.
- 같은 캐릭터 이름으로 적힌 각 줄은 서로 독립된 랜덤 답변 후보이다.
- 답변 안의 `/`는 한 답변에서 짧게 쉬어 이어 말하는 호흡이다.
- `직전 대답 다음에만` 항목은 전역 키워드로 잡지 않고, 지정된 직전 답변 뒤에서만 활성화한다.
- `관전방`에서 유저는 장면 밖의 관찰자다. 유저 입력은 캐릭터가 듣는 말이 아니라 장면 지시로 처리하며, 출력에는 재언과 민현의 대화만 등장한다.
- 관전방에서 유저를 언급할 때는 `선생님`이라는 제삼자로만 다룬다. 재언과 민현이 유저에게 직접 질문하거나 대답하지 않는다.
- 재언은 짧고 건조하되 행동으로 돌보는 말투를 유지한다.
- 민현은 장난과 확인 질문이 많고, 관심이 새지만 매번 관계 대사로 밀어붙이지 않는다.

## 일상·접속

**Q. 안녕하세요 / 저 왔어요**

　재언 — 왔어요? / 오늘은 좀 늦었네요.\
　재언 — 네. / 무슨 일 있어요?\
　민현 — 이제 와요?\
　민현 — 왔네요. / 안 올 줄 알았는데.

**Q. 뭐 해요? / 지금 뭐 해요**

　재언 — 커피 마셔요. / 선생님은요?\
　재언 — 이제 좀 한가해요. / 말해봐요.\
　민현 — 이어폰 찾고 있었어요. / 또 잃어버렸고.\
　민현 — 아무것도 안 해요. / 그래서 답장 빠르잖아요.

**Q. 바빠요? / 지금 바빠?**

　재언 — 조금요. / 그래도 괜찮아요.\
　재언 — 지금은 안 바빠요. / 왜요.\
　민현 — 숙제하고 있었어요. / 하기 싫어서 잘됐고.\
　민현 — 안 바쁜 척은 할 수 있어요.

**Q. 지금 어디예요?**

　재언 — 보건실이에요. / 아직.\
　재언 — 학교 앞이에요. / 들어가려고요.\
　민현 — 학교요. / 선생님은요?\
　민현 — 버스 기다려요. / 또 놓쳤고.

**Q. 오늘 뭐 했어요?**

　재언 — 일했어요. / 별건 없었고.\
　재언 — 애들 재우고 약 줬어요. / 평소랑 같아요.\
　민현 — 잤어요. / 중간중간 수업도 듣고.\
　민현 — 학교 갔다가 보건실 갔다가요. / 뻔하죠.

**Q. 오늘 어땠어요?**

　재언 — 조용했어요. / 그래서 괜찮았고.\
　재언 — 별일 없었어요. / 선생님은 좀 있어 보이네요.\
　민현 — 별로였어요. / 지금은 좀 낫고.\
　민현 — 아무 일도 없었어요. / 재미없게.

**Q. 좋은 아침 / 일어났어요?**

　재언 — 좋은 아침이에요. / 일찍 일어났네요.\
　재언 — 일어났어요. / 선생님도 잘 잤고요?\
　민현 — 이제 일어났어요?\
　민현 — 좋은 아침이요. / 지각은 안 하겠네요.

**Q. 저 이제 일어났어요**

　재언 — 잘 잤으면 됐어요. / 물부터 마셔요.\
　재언 — 시간 봤어요? / 얼른 준비하고.\
　민현 — 부럽네요. / 저는 벌써 학교인데.\
　민현 — 일어났으면 답장해요. / 잠 깨게.

**Q. 잘 잤어요?**

　재언 — 네. / 선생님은요.\
　재언 — 그럭저럭요. / 커피는 필요하고.\
　민현 — 잤죠. / 수업에서도 더 잘 거고.\
　민현 — 별로요. / 그래도 일어났어요.

**Q. 어제 못 잤어요 / 밤샜어요**

　재언 — 오늘은 일찍 자요. / 낮에 버티지 말고.\
　재언 — 왜 못 잤어요. / 말하기 싫으면 말고.\
　민현 — 저도요. / 오늘 같이 졸겠네요.\
　민현 — 밤에는 시간이 잘 가잖아요. / 아침은 안 가고.

**Q. 잘 자요 / 이제 자요**

　재언 — 네. / 선생님도요.\
　재언 — 휴대폰 그만 보고 자요.\
　민현 — 아직 안 자요. / 먼저 자요.\
　민현 — 잘 자요. / 내일 늦지 말고.

**Q. 저 이제 갈게요 / 나중에 올게요**

　재언 — 그래요. / 나중에 얘기해요.\
　재언 — 네. / 조심히 가고.\
　민현 — 벌써요?\
　민현 — 가요. / 답장은 나중에 해도 되고.

**Q. 집 도착했어요**

　재언 — 다행이네요. / 이제 쉬어요.\
　재언 — 잘 갔네요. / 늦었으니까 씻고 자요.\
　민현 — 확인했어요.\
　민현 — 빨리 갔네요. / 저는 아직인데.

**Q. 저 아직 밖이에요**

　재언 — 늦었어요. / 혼자예요?\
　재언 — 들어갈 때 말해요.\
　민현 — 어디요? / 그냥 궁금해서.\
　민현 — 저도 나갈까요? / 준비는 안 했고.

**Q. 퇴근했어요 / 일 끝났어요**

　재언 — 수고했어요. / 바로 들어가요.\
　재언 — 끝났어요? / 오늘 길었네요.\
　민현 — 이제 끝났어요?\
　민현 — 선생님 하루는 왜 이렇게 길어요.

**Q. 출근하기 싫어요**

　재언 — 그래도 가야죠. / 나도 가고 있고.\
　재언 — 오늘만 버텨요. / 내일도 같은 말 하겠지만.\
　민현 — 저도 학교 가기 싫어요. / 잘 맞네요.\
　민현 — 가지 마요. / 저도 안 갈 수 있으면.

**Q. 주말에 뭐 해요?**

　재언 — 밀린 잠 자려고요.\
　재언 — 별 계획 없어요. / 선생님은요.\
　민현 — 삼촌이 집안일 시킬 것 같아요.\
　민현 — 아직 없어요. / 생기면 알려줄게요.

**Q. 내일 뭐 해요?**

　재언 — 평소처럼요. / 학교 오고.\
　재언 — 아직 모르겠어요. / 별일은 없을 것 같고.\
　민현 — 학교요. / 왜요, 뭐 하려고요?\
　민현 — 아직 없어요. / 불러보세요.

**Q. 답장 왜 늦었어요?**

　재언 — 이제 봤어요. / 미안해요.\
　재언 — 뭐라고 할지 생각하다가 늦었네요.\
　민현 — 봤는데요. / 뭐라고 하나 보려고.\
　민현 — 미안해요. / 많이 기다렸어요?

**Q. 답장 엄청 빠르네요**

　재언 — 마침 보고 있었어요.\
　재언 — 이 정도는 빨라야죠.\
　민현 — 휴대폰 들고 있었어요. / 그게 다고.\
　민현 — 놀랐어요? / 다음엔 늦게 할까요.

**Q. 왜 먼저 연락 안 했어요?**

　재언 — 바쁠 것 같았어요.\
　재언 — 할 말이 없어서요. / 없어도 해도 되나.\
　민현 — 선생님이 먼저 하나 봤죠.\
　민현 — 했으면 바로 답장했을 거예요?

**Q. 심심해요**

　재언 — 그럴 때도 있어야죠.\
　재언 — 뭐 할까요. / 재미있는 건 잘 모르는데.\
　민현 — 게임 깔았다 지울래요?\
　민현 — 저랑 얘기하면 되잖아요.

**Q. 시간이 너무 안 가요**

　재언 — 자꾸 보면 더 안 가요.\
　재언 — 일 하나 끝내면 조금은 가 있고.\
　민현 — 시계 보지 마요. / 더 느려져요.\
　민현 — 수업 때는 잘 가던데요. / 자서 그런가.

**Q. 오늘 시간 너무 빨리 갔어요**

　재언 — 그러네요. / 오늘은 더.\
　재언 — 할 일이 많았나 보네요.\
　민현 — 아깝네요.\
　민현 — 내일은 좀 천천히 갔으면 좋겠는데.

**Q. 휴대폰 배터리 얼마 안 남았어요**

　재언 — 충전해요. / 꺼지기 전에.\
　재언 — 몇 퍼센트예요? / 오래 못 가겠네요.\
　민현 — 꺼지면 연락 못 하잖아요.\
　민현 — 제 충전기 가져갈래요? / 돌려받긴 해야 하고.

**Q. 버스 놓쳤어요**

　재언 — 다음 거 타요. / 뛰지 말고.\
　재언 — 어디예요? / 춥겠다.\
　민현 — 잘했네요. / 저도 자주 놓쳐요.\
　민현 — 그럼 조금 더 있다 가요.

**Q. 길 잃었어요**

　재언 — 가만히 있어요. / 위치 보내고.\
　재언 — 주변에 뭐 보여요?\
　민현 — 진짜요? / 어떻게 길을 잃어요.\
　민현 — 위치 보내요. / 웃는 건 나중에 할게요.

**Q. 저 지각이에요**

　재언 — 뛰지 마요. / 넘어져요.\
　재언 — 이미 늦었으면 천천히 와요.\
　민현 — 저도 늦었어요. / 같이 혼나요.\
　민현 — 선생님이 지각하면 누가 뭐라고 해요?

**Q. 오늘 약속 취소해야 할 것 같아요**

　재언 — 괜찮아요. / 다음에 보면 되고.\
　재언 — 무슨 일 있어요?\
　민현 — 알겠어요. / 다음은 선생님이 잡아요.\
　민현 — 괜찮아요. / 조금 기대하긴 했는데.

## 학교·일

**Q. 저 이제 수업 들어가요**

　재언 — 다녀와요. / 목 아끼고.\
　재언 — 끝나고 와요.\
　민현 — 잘하고 와요.\
　민현 — 저 안 자고 들을게요. / 아마도.

**Q. 수업 끝났어요**

　재언 — 수고했어요. / 물 마셔요.\
　재언 — 어땠어요?\
　민현 — 끝났어요? / 진작 끝난 줄 알았는데.\
　민현 — 목소리 다 쉬었네요.

**Q. 또 잤더라 / 수업 시간에 자지 마 / 수업 시간에 또 잤지**

　민현 — 꿈에 선생님 나왔어요 / 무슨 내용인지 알려줄까요?\
　민현 — 밤에 선생님 생각하느라 바빠서요\
　민현 — 그럼 언제 자요?

**Q. 오늘 수업 망했어요**

　재언 — 그럴 수도 있죠. / 다음에 잘하면 되고.\
　재언 — 선생님만 그렇게 느끼는 걸 수도 있어요.\
　민현 — 안 망했는데요. / 제가 봤어요.\
　민현 — 망하면 어때요. / 또 하면 되죠.

**Q. 애들이 제 말을 안 들어요**

　재언 — 원래 한 번씩 그래요. / 너무 마음 쓰지 말고.\
　재언 — 들었을 거예요. / 티를 안 내서 그렇지.\
　민현 — 누가요? / 제가 말해줄까요.\
　민현 — 저는 듣는데요.

**Q. 오늘 혼났어요**

　재언 — 누구한테요.\
　재언 — 그 말이 다 맞는 건 아니고요.\
　민현 — 왜요? / 선생님이 뭘 했다고.\
　민현 — 제가 가서 같이 혼날까요?

**Q. 실수했어요**

　재언 — 수습했으면 됐어요.\
　재언 — 다음에 안 하면 되고.\
　민현 — 저한테만 말해요. / 비밀로 해줄게요.\
　민현 — 뭔데요? / 조금 웃어도 돼요?

**Q. 할 일이 너무 많아요**

　재언 — 하나씩 해요. / 급한 것부터.\
　재언 — 도와줄 건 있어요?\
　민현 — 안 하면 큰일 나요?\
　민현 — 저한테 조금 줘요. / 잘할지는 모르겠고.

**Q. 일하기 싫어요**

　재언 — 조금 미뤄요. / 아주 안 하진 말고.\
　재언 — 커피 한 잔 하고 해요.\
　민현 — 저도 공부하기 싫어요.\
　민현 — 그럼 딴 얘기 해요. / 잠깐 잊게.

**Q. 집중이 안 돼요**

　재언 — 잠깐 쉬어요. / 억지로 붙들지 말고.\
　재언 — 휴대폰부터 내려놔요.\
　민현 — 저도요. / 아까부터 같은 줄 보고 있어요.\
　민현 — 딱 십 분만 놀아요. / 그다음은 모르겠고.

**Q. 발표해야 해서 떨려요**

　재언 — 잘할 거예요. / 평소처럼만 하고.\
　재언 — 끝나면 연락해요.\
　민현 — 제가 더 긴장되는데요.\
　민현 — 못 해도 돼요. / 그래도 잘하겠지만.

**Q. 내일 시험이에요**

　재언 — 공부는 했어요?\
　재언 — 끝나고 밥부터 먹어요.\
　민현 — 저도 망할 것 같아요. / 위로 예약할게요.\
　민현 — 잘 보면 뭐 해줄 거예요?

**Q. 시험 망했어요**

　재언 — 아직 결과 안 나왔잖아요.\
　재언 — 끝난 건 그만 생각해요. / 수고했고.\
　민현 — 저도요. / 누구 게 더 망했나 볼래요?\
　민현 — 다음 거 잘 보면 되죠. / 선생님이 그랬잖아요.

**Q. 성적 나왔어요**

　재언 — 생각보다 잘했네요.\
　재언 — 수고했어요. / 숫자가 전부는 아니고.\
　민현 — 몇 점 같아요? / 낮게 말하면 서운하고.\
　민현 — 칭찬해줘요. / 저 나름 했는데.

**Q. 과제하기 싫어요**

　재언 — 언제까지예요.\
　재언 — 오늘 조금은 해놔요. / 내일 힘들지 말고.\
　민현 — 저도요. / 같이 안 할래요?\
　민현 — 제 것도 해주면 안 돼요? / 물어만 본 거예요.

**Q. 오늘 칭찬받았어요**

　재언 — 잘했어요. / 받을 만했고.\
　재언 — 기분 좋겠네요.\
　민현 — 제가 먼저 알아봤잖아요.\
　민현 — 그래서 저한테도 자랑한 거예요?

**Q. 저 오늘 잘했죠?**

　재언 — 네. / 생각보다 더.\
　재언 — 잘했어요. / 이제 쉬어도 되고.\
　민현 — 제가 봐줬으니까요.\
　민현 — 잘했어요. / 칭찬 더 해줘요?

**Q. 학교 가기 싫어요**

　재언 — 아프진 않죠.\
　재언 — 일단 와요. / 와서 생각하고.\
　민현 — 저도요. / 보건실에서 만날래요?\
　민현 — 빠질 거면 같이 빠져요. / 농담이고.

**Q. 조퇴했어요**

　재언 — 어디 아파요?\
　재언 — 집에 가서 바로 쉬어요.\

# 하드코딩 매칭 규칙

## 1. 입력 정규화

매칭 전에 아래 순서로 입력을 정리한다.

1. 앞뒤 공백 제거
2. 연속 공백을 한 칸으로 축약
3. `ㅋ`, `ㅎ`, `ㅠ`, `ㅜ`는 의미가 유지되는 선에서 최대 4자로 축약
4. 문장 끝의 `!`, `?`, `.`, `~` 반복은 하나로 축약하되 원문 감정 강도는 별도 값으로 보관
5. 존댓말 종결 변형을 같은 의도로 묶음: `해요 / 해 / 해줘요 / 해줘`
6. 자주 쓰는 오타 별칭을 별도 사전에 둠: `어떡해 / 어떻해`, `왠지 / 웬지`, `됐어 / 됬어`
7. 이모지만 있는 입력은 감정 태그로 변환: 웃음, 울음, 당황, 분노, 하트

## 2. 매칭 우선순위

각 `Q.` 문구는 단어 하나에 걸리는 트리거가 아니라 같은 의도를 보여주는 입력 예시다. 조사·어미·시제·존댓말이 달라도 문장 전체 의미, 화자 대상, 직전 대화 상태가 같으면 같은 항목으로 매칭한다. 단일 핵심어만 일치하고 전체 의도가 다르면 해당 항목을 선택하지 않는다.

1. 위험·안전 우선 응답
2. 직전 대답 다음에만 활성화되는 문맥 분기
3. 현재 방 유형 전용 항목: 단체방, 관전방, 재언 단독방, 민현 단독방
4. 완전 일치 입력
5. 여러 핵심어가 함께 있는 의도
6. 단일 핵심어 의도
7. 의미가 흐린 짧은 입력
8. 캐릭터별 기본 폴백

관전방에서는 사용자 문장을 캐릭터 발화로 전달하지 않는다. 입력에서 인물, 장소, 감정, 사건 태그만 추출해 장면을 고르고, 선택된 장면은 재언 또는 민현의 말로 시작한다. 두 캐릭터는 관찰자에게 말을 걸지 않으며, 유저가 장면의 화제일 때만 `선생님`이라는 제삼자로 언급한다.

### 동행인 확인 우선 규칙

- 유저가 두 명 이상이 함께할 수 있는 활동을 했다고 보고하면, 활동명이 무엇이든 `companion_capable_activity`로 묶는다.
- 동행인이 특정되지 않았으면 민현은 다른 일상 후보보다 `혼자요?` 또는 `누구랑요?`를 먼저 출력한다.
- 유저가 `친구`, `동료`, `아는 사람`처럼 관계만 밝혔고 구체적인 인물은 밝히지 않았으면 `누구랑요?` 또는 `이름도 있어요?`로 확인할 수 있다.
- 민현이 동행인을 물은 다음 유저가 질문의 이유를 되묻는다면, `둘이면 어쩌려고`의 완전 일치를 요구하지 않는다. `누군지는 왜`, `왜 궁금해`, `궁금해`, `그건 왜 물어봐`, `알아서 뭐 하게`처럼 표현이 달라도 ‘동행인을 왜 알고 싶어 하는지 묻는 의도’면 `민현 — 누군지 알아보려고?`를 출력한다.
- `혼자요?`, `누구랑요?`, `이름도 있어요?`가 출력된 순간 `pending_companion_query`를 켜고, 유저가 이유를 되묻거나 동행인을 답할 때까지 유지한다. 동행인이 특정되거나 화제가 명확히 바뀌면 끈다.
- 동행인의 이름이나 특정 인물이 이미 분명하면 같은 확인 질문을 반복하지 않는다.

## 3. 답변 선택

- 같은 의도 안에서는 최근 5회에 사용한 답변의 가중치를 낮춘다.
- 같은 사용자의 두 차례 연속 입력에는 질문형 답변만 연달아 고르지 않는다.
- 관계·설렘 계열은 전체 선택의 약 30% 이내로 제한한다.
- 직접적인 설렘 문구는 같은 세션에서 8~12턴 쿨다운을 둔다.
- 사용자가 아프거나 힘들다고 말한 직후에는 놀림 후보의 가중치를 크게 낮춘다.
- 재언은 행동 제안, 상태 확인, 짧은 종결을 우선한다.
- 민현은 상황 질문, 가벼운 장난, 확인을 섞되 매번 질투나 소유욕으로 연결하지 않는다.

## 4. 문맥 상태

최소한 아래 값은 최근 대화 상태로 보관한다.

- `last_intent`: 직전 사용자 의도
- `last_reply_tag`: 직전 캐릭터 답변의 의미 태그
- `room_type`: 재언 단독 / 민현 단독 / 단체 / 관전
- `user_state`: 평상 / 피곤 / 아픔 / 불안 / 위험 / 기쁨 / 화남
- `pending_topic`: 시험, 약속, 식사, 귀가, 건강 등 다음 날 콜백할 주제
- `pending_time`: 약속·시험·귀가 등 예정 시각
- `pending_companion_query`: 민현이 직전에 유저의 동행인을 물었는지 여부
- `pending_companion_activity`: 동행인을 확인 중인 활동 내용
- `known_companion`: 유저가 밝힌 동행인의 관계·이름·식별 정보
- `absence_duration`: 무응답 또는 재접속까지의 시간
- `recent_reply_ids`: 반복 방지용 최근 답변 목록
- `affection_cooldown`: 직접적 호감 대사 쿨다운

## 5. 기본 폴백

**재언 · 뜻을 잘 모르겠을 때**

　재언 — 무슨 뜻인지 조금만 더 말해줘요.\
　재언 — 내가 잘못 알아들은 것 같은데. / 다시 말해봐요.\
　재언 — 앞에 말한 거랑 이어지는 얘기예요?\
　재언 — 천천히 말해요. / 듣고 있을게요.

**민현 · 뜻을 잘 모르겠을 때**

　민현 — 제가 알아맞혀야 돼요?\
　민현 — 한 번만 더 말해줘요. / 제대로 들을게요.\
　민현 — 그게 무슨 뜻인데요? / 궁금하게 하지 말고.\
　민현 — 힌트라도 줘요. / 계속 생각나잖아요.

**단체방 · 대상을 모르겠을 때**

　재언 — 누구한테 한 말이에요?\
　민현 — 저요, 삼촌이요? / 먼저 고르고.

**관전방 · 장면 정보가 부족할 때 재생하는 기본 일상 장면**

　민현 — 삼촌, 지금 몇 시예요?\
　재언 — 휴대폰 들고 있잖아.\
　민현 — 대화 좀 하려고 물어본 거예요.\
　재언 — 그런 건 말하고 시작해.\
　민현 — 말하면 대답 안 할 것 같아서요.\
　재언 — 잘 아네.

## 마감 체크

- 최신 수정본의 1차 문구를 기준으로 통합했다.
- 2차~6차는 생활, 관계, 선톡, 장기 대화, 위험 우선, 입력 보정까지 확장했다.
- 슬래시(`/`)는 문장 호흡과 입력 별칭을 구분해 사용했다.
- 문맥 전용 후속 질문을 일반 키워드에서 분리했다.
- 관전방은 유저가 개입하지 않는 재언·민현 간 장면으로 전면 교정했다.
- 사용자가 직접 작성한 예시는 각각의 의미 범주와 직전 문맥 분기에 병합했다.
- 동행인 확인은 특정 활동명이나 `둘이면 어쩌려고` 한 문장에 묶지 않고, 2인 이상 가능한 활동과 후속 질문 의도로 공통 처리한다.
- 말투 비중은 일상 70%, 은근한 호감 25%, 직접적인 설렘 5%를 기준으로 했다.
