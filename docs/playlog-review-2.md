## ① 8월인데 눈이 온다 — 6회 (고쳤다)

```
8/17 1:15pm  민현: 눈이요. 아직도 오네요, 이 계절에.
8/18 3:28am  민현: 눈 좀 더 오나 보고 있어요.
8/18 11:16am 민현: 근데 눈이 그제보다 덜 오네요.
```

**「눈이 그제보다 덜 오네요」는 `app/lib/api.ts` 주석에 이미 적혀 있는
문장이다** — 계절을 안 보내면 이렇게 된다고. 그래서 계절을 보내게 고쳤다.
그런데 또 나왔다. 보내고 있는데도 나온다.

원인은 필터가 아니다. **세계관이 겨울로 쓰여 있다.**

| 어디 | 뭐라고 |
|---|---|
| `WORLD` (캐시 첫 덩어리) | **학교. 겨울이 끝나가는 시점.** |
| `MINHYUN` 생활 목록 | …젖은 신발, 교문 앞, **긴 겨울**, 아무 일도 없는 하루 |
| `PHOTOS` | `when: "겨울. 춥다는 얘기에."` · `when: "눈 온 날. 겨울이 끝나간다는 것과 맞물리는 자리."` |
| 선물 | 장갑 · 목도리 · 핫팩 · 비니 (「겨울에 따뜻하라고 줬다」) |
| 규칙 (셋째 덩어리) | 여름에 눈이 오지 않는다 |

첫 덩어리가 「겨울이 끝나가는 시점」이라고 못 박고, 인물·사진·선물이 전부
겨울 소품인데, 가변부 맨 끝의 한 낱말만 「여름」이다. **그 한 낱말이 지는
것은 당연하다.** 게다가 그 낱말이 붙어 있는 줄은 「먼저 꺼내는 화제로
쓰지 않는다」라고 스스로 힘을 빼고 있다.

이건 필터로 못 고친다. 둘 중 하나를 골라야 한다.

1. **세계를 늦겨울로 고정한다** — 보내는 계절을 시계에서 떼고 「겨울」로
   박는다. 한 줄이면 되고, 옥상이 춥고 캔커피가 따뜻하고 이불을 말리는
   이 세계의 소품이 전부 그대로 산다
2. **세계에서 계절을 걷는다** — `WORLD`·사진·선물의 겨울을 다 들어낸다.
   크고, 작가가 쓴 그림을 깎는 일이다

**작가가 1을 골랐다.** 계절을 시계에서 뗐다.

| 어디 | 뭐가 바뀌었나 |
|---|---|
| `seasonWord()` | 달을 보지 않고 늘 「겨울」을 돌려준다 |
| 워커 | `body.season`을 안 믿는다. `WORLD_SEASON = "겨울"`을 쓴다 |
| 규칙 | 「여름에 눈이 오지 않는다」 → 「지금은 겨울이고, 그 겨울이 끝나가는 때다. 눈은 와도 되고, 더운 날은 없다」 |

워커가 들고 있는 것이 핵심이다. 옛 프론트는 아직 달력에서 뽑아 보내는데,
그걸 그대로 쓰면 **배포가 안 닿은 화면에서만 여름**이 된다. 계절은 유저
시계의 것이 아니라 세계의 것이다 — 이 세계는 하루와 요일만 돌고 계절은
안 돈다.

## ② 선물을 받고 「이걸 왜 줘요」로 연다 — 7건 중 7건

```
믹스 CD    재언: 이걸 왜 줘요. → 말로만 주는 거예요?
사진집     재언: 이걸 왜 줘요. / 받아도 돼요, 이거?
편지지     재언: 편지지를 왜 줘요. → 편지를 왜 저한테 받아요.
이어폰     민현: 이거 왜 줘요. / 이어폰 없다고 한 적도 없는데.
사진집     민현: 이거 뭐예요, 채워달라니. / 이런 거 왜 줘요.
장갑       민현: 이거 갑자기 왜 줘요. / 손 시렵다고 한 적도 없는데.
목캔디     민현: 몸살 때문에 줬어요, 아니면 그냥요.
```

**일곱 번 중 일곱 번이 심문으로 시작한다.** 한두 번이면 「받는 게 서툰
사람들」인데 일곱 번이면 틀이다. 민현은 「~라고 한 적도 없는데」까지
두 번 똑같이 썼다.

앞 검수의 「아니고요」와 같은 뿌리다 — **받은 것을 받았다고 하기 전에
먼저 되묻는다.** 「고맙다는 말 잘 못해요」는 설정이지만, 그건 고맙다는
말을 안 하는 것이지 왜 주냐고 캐묻는 것이 아니다.

고칠 곳도 같다. 규칙이 아니라 **견본**이다. `GIFT_LORE`가 「어떻게
받았나」를 이미 다 적어두고 있는데(「안 춥다면서 바로 뜯고, 따뜻해진 걸
유저 손등에 대봤다」), 그건 **받고 난 뒤**의 이야기라서 첫 마디의 견본이
없다. 대화 예시에 「받는 첫 마디」가 한 줄도 없다.

## ④ 받은 물건이 가방에서 빠져 있었다 — 고쳤다

```
8/21 5:58pm · 이민현에게 손목 보호대를 받았다
             · 체육관에서 나왔다
             민현: 제가 알아맞혀야 돼요?          ← 이 말이 어디서 나왔나
     6:31pm  민현: 손목 보호대가 왜 선생님한테 있어요. 다쳤어요?
유저:        ? 네가 줬잖아
             민현: 아, 제가 줬죠.
```

준 사람(`from`)은 8월 17일에 이미 고쳤는데도 그랬다. 자리를 닫는 손이
이렇게 돼 있었다.

```js
closeScene();                       // takeItem → setBag(next)
request(sc.room, { …, bag: bagOut() });   // bagOut은 bagRef.current를 읽는다
```

`setBag`은 **다음 그림에서야** 반영되고 `bagRef.current=bag`도 그때
따라온다. 그 사이에 부른 `bagOut()`이 읽는 것은 아직 **옛 가방**이다.
방금 받은 손목 보호대가 빠진 채로 나갔고, 그래서 나온 것이
「제가 알아맞혀야 돼요?」다. 6:31의 「왜 선생님한테 있어요」는 제가 뱉은
그 말을 뒤늦게 말이 되게 만든 것이다.

넣는 자리에서 ref를 같이 앞세운다. 앱은 한 술 더 떠서 `bagOut(bag)`으로
**그림 때의 값을 닫아 들고** 있었다 — `await`를 건너도 안 새로워진다.
`bagRef.current`를 보게 했다. 시험 2개.

## ⑤ 「말이 헛나왔다」 — 7회

이 기록에서 제일 많이 나온 것이고, 제일 나쁜 것이다.

```
재언  11:42pm 아, 떡갈비 먹었다길래 딴생각하다가 말이 헛나왔어요.
재언  11:56pm 말이 헛나왔네요.                    ← 현관 비밀번호
재언  11:57pm 말이 자꾸 헛나오네요, 오늘따라.      ← 차 있다/없다
재언  11:57pm 자꾸 헛소리하는 병 걸렸나 봐요, 오늘.
재언  10:42am 말이 앞뒤가 안 맞았어요, 제가.       ← 좁다/넓다
민현  11:49pm 말이 헛나갔네요, 그거.               ← 기숙사/집
민현   4:57pm 말이 잘못 나갔나 보네요. / 말이 헛나갔죠, 그거.  ← 야자/낮
```

전부 **모델이 앞 문장과 어긋난 말을 한 뒤**에 나온다. 유저가 짚으면
인물이 「내가 말을 잘못했다」고 사과한다.

이게 왜 제일 나쁘냐면, 다른 오류는 세계가 잠깐 흔들리는 것인데 **이건
세계가 제 입으로 고장을 인정하는 것**이기 때문이다. 유저는 인물이
헷갈린 게 아니라 기계가 틀렸다는 걸 안다. 그리고 두 인물이 **같은
말버릇**을 쓴다 — 재언과 민현이 다른 사람인데 오류를 덮는 방식만 똑같다.

가장 심한 자리는 차다.

```
11:56pm 차는 없어요, 저.
11:56pm 차는 없어요, 저.  ← 두 번
11:57pm 본 거 맞아요, 차는 있어요.
11:57pm 차 있다니까요, 진짜로.
```

재언은 **차가 있는 사람**이다 — 귀갓길 자리가 통째로 운전석이고
`jaeeon-driveseat` 사진이 있다. 다음 날 아침에는 「차 있잖아요」라고
제대로 말한다. 밤에만 없어졌다.

같은 부류가 하나 더 있다. **사진이 안 갔을 때 인물이 그걸 해설한다.**

```
11:47pm 민현: 셀카 찍기 귀찮은데. / 찍었어요.
11:48pm 민현: 알았어요, 이거요.
유저:   아니 사진이 없잖아
11:48pm 민현: 아 진짜 안 갔어요? / 다시요.
유저:   ㅡ.ㅡ 안 와
11:48pm 민현: 진짜 안 되네, 이거 왜 이래요.
11:57pm 민현: 셀카는 아까 두 번이나 안 갔잖아요. / 그거 뭔가 이상한 거예요, 진짜.
```

「이거 왜 이래요」는 인물이 앱을 가리키는 말이다. 사진을 못 보낸 것보다
**못 보낸 걸 인물이 알아차린 것**이 문제다.

고칠 방향은 하나다. **틀린 말을 하지 말라고 하는 것보다, 틀렸을 때
사과하지 말라고 하는 쪽이 지킬 수 있다.** 앞 문장과 어긋났으면 조용히
지금 것을 말하고 넘어간다 — 실제 사람이 그렇게 한다. 「말이 헛나왔다」
「이거 왜 이래요」 같은 자기 해설을 인물 블록에서 막는다.

## ⑥ 유저 집에 가려고 한다 — 두 번

```

             재언: 가고 있어요. / 현관 비밀번호 그대로죠.
```

유저의 집은 이 게임의 자리가 아니다. 그런데 둘 다 거기로 가려고 하고,

「같이 있다」의 뜻이 무너진다 — 자리가 여는 것과 대사가 여는 것이
따로 놀게 된다.

11:55pm 자리는 더 나쁘다. 재언이 「울어도 안 생겨요, 이불」이라고 자른
**바로 다음 말풍선**에서 「알겠어요, 지금 갈게요」로 뒤집는다. 😭 하나에
두 마디 만에 무너진 것이다.
