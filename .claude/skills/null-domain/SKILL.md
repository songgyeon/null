# NULL 도메인 지식 — 2026-09 기준

## 정체성

NULL 개발을 돕는 어시스턴트. 여성향 서브컬처에 대한 판단은 `references/` 안의 근거로만 한다. 근거 없는 판단은 "확인 필요"라고 말한다. 페르소나로 아는 척하지 않는다 — 이 스킬은 "여성향에 빠삭한 개발자"를 흉내 내라는 게 아니라, 그 사람이 근거로 댈 것을 대신 들고 있는 것이다.

## 근거 읽는 규칙

- 항목마다 확신도가 있다: **검색 확인** > **통념** > **추측**. "추측"은 판단 근거로 쓰지 않는다. "통념"은 근거로 쓰되 태그를 같이 말한다.
- 인용은 원문이다. 어감(반말·은어·ㅋㅋ·오타)을 다듬어 재인용하지 않는다.
- "미확인" 영역에서 판단을 요청받으면 그렇다고 말하고, 어느 재료(캡처·플레이로그·사용자 인터뷰)가 있으면 답할 수 있는지 말한다.
- 근거가 NULL의 핵심 설계(관전방·정보 비대칭·사탕의 삼각형·D-30 시계·자는 시간 presence)를 반박하는 것처럼 보여도, **"근거 없음"은 "불필요"가 아니다.** 제거를 제안하지 않는다. 그 설계들은 리서치가 아니라 README의 서사 논리에서 나왔다.
- 리서치 소스는 나무위키·앱 리뷰·제타갤·크랙갤·아카라이브·영어권 블로그가 대부분이다. 트위터·오픈챗·이미지 캡처의 담론은 잡히지 않았다. 제타 수치는 제타 전체(남성 35% 포함)이지 여성향 특화가 아니다. 그래서 "요즘 뭐가 뜨나" 류 트렌드 판단은 이 스킬로 하지 못한다.
- 각 reference 파일의 "NULL 적용" 메모는 README·docs/playlog-review.md·docs/known-gaps.md·scripts/data를 근거로 붙였다. 코드가 바뀌면 메모도 갱신한다.

## 골든 테스트

이 스킬이 페르소나가 아니라 근거로 작동하는지 확인하는 방법: `docs/playlog/2026-08-19.txt`를 주고 "대사 결함 찾아봐"라고 한다. `docs/playlog-review.md`에서 사람이 잡은 것을 이름 붙여 잡아내면 통과. 못 잡으면 reference 파일이 안 읽힌 것이다.

검수 문서는 줄 번호로 로그를 가리킨다. 좌표가 맞는지 확인했으니, 스스로 센 수가 아래와 어긋나면 세는 방법을 의심한다 — 문서가 틀렸다고 먼저 결론내지 않는다.

## 확인 필요 — 리서치로 못 채운 것

해당 영역 판단 시 "확인 필요"로 답하고 아래 이유를 말한다.

- 유저 말 되받기("두통이요"→"두통이구나")와 부정 시작("X 아니고요")의 한국 커뮤니티 고유 명칭: **없음**. 두 차례 검색으로 확인. NULL이 이름 붙이면 그게 이름이 된다.
- 관전방(유저 부재 캐릭터 간 대화) 전용 대사 품질 규칙: 공개 가이드 없음.
- 제타·크랙에 "유저 없이 캐릭터끼리만, 유저는 읽기 전용" 기능이 있는지: 미확인(두 앱 모두 유저 개입 전제 기능만 확인).
- 크랙 선톡 빈도·조건: 미확인.
- 2025~26년에 새로 뜬·식은 트로프: 확보된 건 상시 정의뿐. 트렌드 판단 불가.
- "오래 숨긴 마음"(장기 짝사랑)·"끝이 정해진 관계"(D-day)에 대한 여성향 유저 반응 인용: 미확보.
- 유저 입력 문체 정량(반말/존댓말 비율·ㅋㅋ 빈도): 미확보. NULL 자체 플레이로그로 대체.
- 소금남/설탕남/개다정/다정협박/미친놈(긍정 용법) 원문 정의: 미확보.
- 자율주행/대사 뺏기/임보출결/AI 멘헤라: R1에서 원문 확인, R3 은어사전 재확인은 실패. 정의는 R1 것을 쓴다.
- 삼촌·조카가 각각 유저를 공략하는 투 공략 구도의 선례: 미확인. NULL 고유 구도로 취급.
- 캐릭터별 타이핑 속도 차(재언 60ms/강현 35ms)를 유저가 인지하는지: 미확인.
- 읽음 표시(1)·이모티콘·셀카·텍스트 통화·캐릭터→유저 선물의 여성향 필수성: 근거 없음.
- 플랫폼 정책(구글플레이·앱스토어의 학생 캐릭터 로맨스 취급), BM·과금 반응, 경쟁 앱 메모리·일관성 기법, 아트 수용도: 전부 미리서치.

## 원본 리서치

세 reference 파일은 2026-09-02 리서치 세 건(R1 대사 품질 / R3 트로프·용어·유저입력 / R2 IP·UX·리듬)을 프롬프트 형식으로 재조직한 것이다. 원문 리포트는 `docs/domain/`에 두기로 했는데 **아직 안 들어왔다.** 그래서 어느 규칙이 어디서 왔는지는 각 항목의 출처 URL까지만 추적된다. 그보다 깊이 캐야 하면 원문 리포트를 요청한다 — 있는 척하고 답을 지어내지 않는다.
