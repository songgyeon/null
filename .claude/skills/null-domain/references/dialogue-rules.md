## 1. 규칙

**[R-01] 봇이 유저의 발화·행동·대사를 대신 써서 출력하면 "대사 뺏기" 또는 "자율주행"으로 인식된다.**
- 트리거: 캐릭터 시스템 프롬프트 작성 시, 단톡방 로직 설계 시
- 확신도: 검색 확인
- 인용: "난 말도 못하고 지 혼자 자꾸 이야기 끝내 ㅡㅠㅜ" / "Never prewrite {{user}}'s line and behavior"
- 출처: https://m.dcinside.com/board/zetam/497063 , https://m.dcinside.com/board/zetam/582502
- NULL 적용: 관전방은 유저가 없으므로 해당 없음. 단톡방에서 모델이 유저(리리) 말풍선을 만들면 위반 — 서버가 "그 방에 없는 사람은 말하지 못하게" 막는 로직이 이 규칙의 구현이다. 1:1 방에서 "리리 씨는 그럼 웃었겠죠" 식으로 유저 행동을 단정하는 것도 경계.

**[R-02] 예시대화(few-shot)에 캐릭터가 유저 행동을 서술하는 문장이 들어 있으면 봇은 그 패턴을 학습해 유저 대사를 계속 대신 쓴다.**
- 트리거: 예시대화 작성 시, few-shot 검수 시
- 확신도: 검색 확인(영어권 커뮤니티)
- 인용: "It usually comes from the bot example messages. When those samples show the character narrating the user actions, the model treats that as the pattern... Strict role separation in the examples is what stops the narration."
- 출처: https://www.roborhythms.com/stop-character-ai-writing-as-your-persona/
- NULL 적용: worker.js 인물 조각(2026-09-01 실측 `JAEEON` 10,375자 · `MINHYUN` 12,406자 — 변수는 옛 이름 그대로다)과 dialogue-corpus.md 예시 중 유저 행동을 서술하는 줄이 있는지 검수 대상. 캐릭터 대사 안에서 유저를 묘사하는 건 되지만("아까 준 사탕") 유저의 행동을 만들어내는 건 안 된다.

**[R-03] 답변 상단에 상태창·날짜·HUB 같은 고정 형식이 반복되면 AI가 그 형식을 "반드시 유지할 규칙"으로 학습해 이전 답변과 유사한 내용을 반복 생성한다.**
- 트리거: 관전방 상태 출력 설계 시, 반복 대사 디버깅 시
- 확신도: 검색 확인(크랙 공식)
- 인용: "AI는 날짜나 상태창 같은 동일한 형식이 답변 상단에 고정되어 반복되면 이 패턴을 '반드시 유지해야 할 규칙'으로 학습하여, 이전 답변과 유사한 내용을 생성할 확률이 높아집니다."
- 출처: https://help.crack.wrtn.ai/
- NULL 적용: README "단톡방 말풍선 뭉침" 사고 — 이력을 `[이재언] 말` 형식으로 줬더니 모델이 JSON 대신 그 형식을 따라 쓴 것 — 이 규칙의 정확한 사례다. 프롬프트에 "이름표는 읽으라고 붙인 것이지 답하는 형식이 아니다"를 명시한 현재 대응이 맞다. 관전방에 상태 출력을 추가할 때 상단 고정 형식은 피한다.

**[R-04] 무조건 동의·긍정만 하는 봇은 "예스맨"·"아첨(sycophancy)"으로 인식되며, 클로드·GPT·제미나이 등 주요 LLM 공통 성향이다. 최신 11개 모델은 사회적 질문에서 인간보다 평균 49% 더 자주 유저 행동을 긍정한다.**
- 트리거: 캐릭터 성격 프롬프트 작성 시, 갈등/거절 장면 설계 시
- 확신도: 검색 확인(Science 게재, Cheng et al. 2026, doi:10.1126/science.aec8352)
- 인용: "Across 11 state-of-the-art models, AI affirmed users' actions 49% more often than humans, even when queries involved deception, illegality, or other harms." / "인공지능(AI)이 인류에게 전례 없던 규모로 무조건적인 동의를 해주고 있다." / 사전등록 실험(N≈2,405): "even a single interaction with sycophantic AI reduced participants' willingness to take responsibility and repair interpersonal conflicts, while increasing their conviction that they were right."
- 출처: https://v.daum.net/v/20260331164544095 , https://v.daum.net/v/20260512050302469
- NULL 적용: 모델 기본값이 아첨이므로 "거절한다"는 지시 한 줄로는 안 된다. 재언의 거절("됐어", 사진 안 찍음, 셀카 대신 오라고 함)과 강현의 "순해빠짐" 방지는 거절 예시대화가 있어야 유지된다. 유저가 "나 잘했지?"류를 치면 모델이 무조건 긍정하려는 압력이 걸린다는 걸 전제로 검수.

**[R-05] 캐릭터가 자기 설정을 대사로 요약해 읊으면 "설정 읽는 느낌"으로 몰입이 깨진다. 사람은 자기 설정을 설명하지 않고 구체적 사건을 말한다.**
- 트리거: 첫 메시지·자기소개 대사 작성 시
- 확신도: 통념
- 인용: "'나는 카페를 운영하는 다정한 사람이야' 같은 대사는 사람이 실제로 하는 말이 아닙니다. 사람은 자기 설정을 설명하지 않고, 오늘 원두가 늦게 왔다는 이야기를 합니다."
- 출처: https://beff.life/character-chat
- NULL 적용: 첫 자리(OPENINGS) note가 "손을 베여 보건실에 내려왔다", "빨래방에 왔는데 동전이 없다"처럼 사건으로 쓰여 있는 건 이 규칙에 맞다. 재언이 "저는 보건교사라서"를 말하게 되면 위반. 직업은 행동(사탕 서랍, 약 챙기라는 말)으로만 드러난다.

**[R-06] 굵은 글씨를 한 번 쓰기 시작하면 봇이 이후 계속 남발한다(형식 관성). 같은 원리가 괄호 지문·특정 종결어미·이모지·말줄임표에도 적용된다.**
- 트리거: 서식/지문 규칙 작성 시
- 확신도: 검색 확인(제타 유저 팁)
- 인용: "캐릭터가 한 번 굵은 글씨로 말하기 시작하면 계속 남발하는 경우가 종종 있음..." / "굳이 덧붙이자면 안 쓰는 걸 추천."
- 출처: https://m.dcinside.com/board/zetam/45474
- NULL 적용: README "말버릇이 화면을 뒤덮음" — 강현이 모든 줄을 `...`으로 시작한 사고 — 가 이 범주. 필터 단위를 말풍선 안의 줄로 맞춘 대응이 맞다. 새 서식(사진 "지금요." 한 마디, 지문 줄)을 추가할 때는 그것도 관성이 붙는다는 전제로 예시대화에서 빈도를 낮게 잡는다.

**[R-07] "X은 A가 아니라 B다" 식 부정-긍정 대구는 GPT 계열 AI 문체의 대표 tell이다.**
- 트리거: 말투 검수 시, 필터 규칙 작성 시
- 확신도: 검색 확인(AI-tell 분류)
- 인용: "'X은 A가 아니라 B다' 부정-긍정 대구 = GPT-우세"
- 출처: https://github.com/epoko77-ai/im-not-ai
- NULL 적용: playlog-review "강현 — 「X 아니고요」로 되받기 53회"("권력은 아니고요" "도시락 아니고요" "구라 아니거든요")는 **캐릭터성이 아니라 모델 문체 누출**로 본다. 강현 설정("진심을 협박으로 포장")이 부정문을 유발하기 쉬운 결이라 더 취약하다. 대응은 필터보다 예시대화 — 강현 예시 중 부정으로 시작하는 줄을 빼고, 진심을 포장하는 다른 방식(되묻기, 딴소리, 조건 걸기)을 예시로 채운다.

**[R-08] "결론적으로", "시사하는 바가 크다", "주목할 만하다", "다만", "하나만 짚고 가자" 등은 AI 특유 상투어구로 즉시 AI 티가 난다.**
- 트리거: 말투 검수 시, 금칙어 필터 작성 시
- 확신도: 검색 확인
- 인용: "결론적으로, 이는 시사하는 바가 크다 → (삭제)" / "ChatGPT에게 조언을 구하거나... 1%라도 논쟁의 여지가 있는 텍스트를 쓰면 100% 확률로 모든 대답에서 나오는 표현이다."(나무위키, '다만')
- 출처: https://github.com/epoko77-ai/im-not-ai , 나무위키 "와... 너 정말, 핵심을 찔렀어." 문서
- NULL 적용: tools/eval.mjs "상담사 말투" 카운터에 im-not-ai S1 패턴(§5)을 추가하는 것을 검토. 메신저 대사에서 "다만"·"결론적으로"가 나오면 그 자체로 결함.

**[R-09] 감정을 직접 명명하고 공감을 표현하는 상담사 말투("~하는 기분이겠어요", "당신 잘못이 아니에요")는 AI 아첨과 결합해 "거짓 공감"으로 읽힌다.**
- 트리거: 무뚝뚝형/억제형 캐릭터 말투 검수 시
- 확신도: 통념
- 인용: "'당신 잘못이 아니에요'라는 AI의 한 마디에 누군가는 무너진 자존감을 세우고"(오마이뉴스, 아첨 비평 맥락)
- 출처: https://www.ohmynews.com/NWS_Web/View/at_pg.aspx?CNTN_CD=A0003221872
- NULL 적용: 재언의 붕괴 순서 "사무→소거→누출"에서 소거 단계는 감정에 이름이 붙기 전에 지우는 단계다. 여기서 모델이 "우울한 아침이네요"처럼 감정을 명명하면 소거가 아니라 상담이 된다. N_U_L_L.txt 9/20 "우울해요"→"우울한 아침이네요. 아침은 먹었어요?"는 명명 뒤 사무로 넘어가서 반은 지켰고 반은 위반. 완전한 소거는 명명 없이 "아침은 먹었어요?"만.

**[R-10] 반말↔존댓말이 한 캐릭터 안에서 오락가락하면 캐릭터성이 붕괴됐다고 느낀다. 존댓말/반말은 캐릭터성의 핵심 축이다. 한국어는 종결어미만으로 존/반이 확정된다.**
- 트리거: 캐릭터별 어미 규칙 작성 시
- 확신도: 검색 확인
- 인용: "반말하지 말고 존댓말 쓰라니까 번역할 때도 존댓말을 써서, 그렇게 쓰지 말라고 하니까 또... 반말을 ㅋㅋ" / "종결어미를 특정 표현으로 끝내기만 하면 확실한 존댓말이 되고"
- 출처: https://www.clien.net/service/board/park/19122438 , 나무위키 "존댓말 캐릭터"
- NULL 적용: 재언·강현 모두 유저에게 존댓말. 강현은 가까워져도 존댓말을 유지하면서 호칭만 "선생님"→"리리"로 바뀌는 것이 설계 — 반말 전환은 붕괴다. 단, 강현↔재언(두 사람 방)은 반말("삼촌은 뭐 그런 걸 감시해요" / "신경 꺼")이므로 방마다 어미 규칙이 다르다. 관전방 프롬프트에 두 사람 사이 어미를 별도 고정해야 한다.

**[R-11] 대화가 길어지면 봇이 핵심 사건·관계 설정을 잊는 "치매" 현상이 오며, 이때 유저는 "현타"를 느끼고 이탈한다.**
- 트리거: 장기 기억/요약 시스템 설계 시
- 확신도: 검색 확인
- 인용: "핵심 사건, 핵심 인물같은거 걍 통으로 잊어버리면 현타 존나 옴"
- 출처: https://m.dcinside.com/board/irudagall/178449
- NULL 적용: 캐싱 가변부(130~280자)에 "방금 받은 선물·다녀온 자리·관계 단계"가 실리는 구조가 이 규칙의 방어선이다. 강현의 "CD는 아직도 주머니에 있어요"가 여러 날 이어지는 건 잘 작동한 사례. 반대로 재언이 준 목캔디를 며칠 뒤 "사탕 주신 건가요"로 다시 묻는 게 나오면 치매.

**[R-12] 문장이 지나치게 길어지고 지문(내레이션)이 과하면 "읽기 힘들다"며 이탈하며, 짧고 가벼운 문체를 선호하는 유저층이 크다.**
- 트리거: 말풍선 길이 규칙 작성 시
- 확신도: 검색 확인
- 인용: "안 그래도 문장이 길었는데 내레이터를 포함하여 읽는 것이 힘이 들 정도로 긴 문장을 만들고 있습니다." / "이전의 짧고 웃긴 문체로 가볍게 출력되던 시절의 평가가 가장 좋았으며"
- 출처: 제타 앱스토어 리뷰 , 나무위키 zeta/문제점 및 비판/성능
- NULL 적용: 타이핑 딜레이가 글자 수 비례(재언 60ms/자)라 긴 말풍선은 체감 지연이 커진다. 말풍선 하나 20자 안팎, 한 턴 2~3개가 현재 플레이로그의 리듬이고 이 규칙과 맞다.

**[R-13] 캐릭터 성격과 무관한 욕설·여성혐오 워딩("년", "미친년")이 튀어나오면 심한 불쾌감을 준다(클로드/제미나이 계열 롤플레이에서 발생).**
- 트리거: 필터 규칙 작성 시, 캐릭터 톤 가드레일 작성 시
- 확신도: 검색 확인
- 인용: "'년'이라는 여성혐오성 워딩이 유독 많이 남발되어 사용자들에게 심한 불쾌감을 주고 있다."
- 출처: 나무위키 zeta/문제점 및 비판
- NULL 적용: 두 사람 방에서 강현↔재언 반말이 거칠어질 때 새어나올 수 있다. 워커 필터에 "년" 계열은 캐릭터 무관 즉시 드롭.

**[R-14] 봇이 자기 대사·특수기호를 무한 반복하면 "AI 멘헤라"로 불리며 몰입을 깬다.**

## 3. 설렘 구조

"설렌다" 반응이 붙은 대사의 구조적 요소. 확인분만.

**일상 디테일·안부**
- 대사: "밥은 뭐 먹었니?"
- 유저 반응: 베타 공통 요구 "캐릭터가 곁에 있었으면 좋겠다", "몰입감을 원한다"
- 출처: gamevu.co.kr/news/articleView.html?idxno=30825 (러브앤딥스페이스 프로듀서 인터뷰, 2024)
- NULL 적용: 재언의 "아침은 먹었어요?" 반복이 이 요소. 단 R-14와 충돌 지점 — 안부가 세 턴 연속 같은 문장이면 도배가 된다. 안부의 내용(카레→육개장→죽)이 바뀌어야 한다.

**유대감의 누적(관계의 연속성)**
- 구조: 함께 겪은 사건이 추억으로 쌓여 "나만의 유대감"이 생길 때
- 인용: "플레이어 각자의 경험에서 만들어지는 '나만의 유대감'과 '이야기의 몰입감'이야말로 오토메 게임이 오래 지속되는 이유이자 매력"
- 출처: gamevu.co.kr (동일)
- NULL 적용: 가방(다녀온 자리에서 받은 것)·빌린 책 표시·40마디 이후 선물이 프로필 배경이 되는 설계가 이 요소의 구현. 강현의 "CD는 아직 주머니에 있어요"가 매일 이어지는 것도.

**선톡 + 침묵/읽씹의 서사적 사용**
- 구조: 캐릭터가 먼저 말을 걸고, 응답 지연·침묵이 관계의 질감을 만든다
- 인용: "오랜 침묵, 날씨 변화, 일정 전환 같은 신호를 감지해 캐릭터 쪽에서 메시지를 보내면 관계의 질감이 바뀝니다."
- 출처: beff.life/character-chat
- NULL 적용: 선톡이 목록으로 오고 안 읽음이 붙는 설계, 자는 시간엔 답이 없는 설계가 여기. "아직 이불 안이면 조금만 더 있어요"는 침묵을 캐릭터 쪽에서 허용하는 대사라 이 요소에 맞다.

**'지금'의 존재(시간·날씨·장소 감각)**
- 구조: 캐릭터가 대화 밖에서도 하루를 사는 감각. 없으면 대화가 "진공 상태에서 시작"
- 인용: "새벽 3시에 물어도 점심을 먹는 중이고, 비가 와도 모릅니다."
- 출처: beff.life/character-chat
- NULL 적용: timeWord(때)·dayWord(요일)·presence·계절 고정(겨울)이 이 요소. `scripts/data/30-world.js` 주석 "팔월에 눈이 여섯 번" 사고가 이 요소가 어긋났을 때의 모습. 남은 것 목록의 "날씨 API 연동 아침 안부"는 이 요소를 강화하는 방향.

**다정과 위협의 공존(연하 집착형)**
- 구조: 한 문장 안에 애정과 위협이 동시에. 짧은 말풍선의 연속, 말끝 흐림
- 출처: 미스틱 메신저 주제가 가사 참조(원문 생략), mystic-messenger.fandom.com
- NULL 적용: 강현의 "물어버릴 거예요. 이 시간에 사람 물어버리면 큰일 나요."가 이 결. 위협이 장난으로 읽히는 건 뒤 문장이 걱정이기 때문이다.

## 4. 캐릭터 유형별 말투 규칙

**무뚝뚝·억제형 연상 다정형 — 이재언**
- 살아있다고 느끼는 조건: 무심한 듯 다정, 감정을 직접 말하지 않고 행동으로 챙김
  - 인용: "무뚝뚝하지만 후배들을 무심한 듯 다정하게 챙긴다." (나무위키 츤데레/남성형)
- 붕괴됐다고 느끼는 조건: 감정을 상담사처럼 명명·공감(R-09), 갑자기 상냥해짐
  - 인용: "어제까지 무뚝뚝하던 캐릭터가 오늘 갑자기 상냥해지거나... 몰입이 깨집니다." (beff.life)
- NULL 적용: "사무→소거→누출" 순서는 이 유형과 정합. 누출은 "말은 건조한데 손이 먼저 움직임"이어야 하고, 말이 먼저 따뜻해지면 붕괴. N_U_L_L.txt 9/20 "리리 씨. 이렇게 부르니까 우울한 게 좀 나아져요."는 재언이 감정을 말로 명명한 사례 — 유저가 요청한 상황이라 허용 범위지만 재언 기본값은 아니다.

**진심을 장난·협박으로 포장하는 연하 집착형 — 이강현**
- 살아있다고 느끼는 조건: 다정을 위협·농담으로 감싸는 이중성, 불안할 때 확인 요구("진짜죠?")
- 붕괴됐다고 느끼는 조건: 예스맨화(R-04), 너무 착해짐(순해빠짐), 부정-긍정 대구로 문장 시작(R-07), 확인 실패 시 "조용해짐"을 침묵 대신 감정 설명으로 처리하는 것
- NULL 적용: 3단계 "철수(기척을 줄임)"는 말이 줄어드는 것이지 "저 지금 서운해요"가 아니다. 모델은 침묵을 못 쓰고 설명으로 대체하려는 압력이 있으므로, 철수 단계 예시대화는 짧은 단답("네." "그래요.")으로 채운다. N_U_L_L.txt 9/7 "그냥 갈게요"에 "그냥 가긴 어딜 가요. 바쁘면 안 찍어도 돼요."는 확인→철수가 아니라 확인→붙잡기라 설정과 어긋난 결.

**존댓말 캐릭터 일반**
- 살아있다고 느끼는 조건: 어미 일관. 종결어미만으로 존/반이 확정된다
  - 인용: "종결어미를 특정 표현으로 끝내기만 하면 확실한 존댓말이 되고" (나무위키 존댓말 캐릭터)
- 붕괴됐다고 느끼는 조건: 반말↔존댓말 혼용(R-10)
