# 트로프·용어·유저 입력 — 여성향 AI 캐릭터 챗 (2026-09 기준)

읽는 시점: 캐릭터 설계·설정·마케팅 문장 판단(§1~§3), 유저 피드백·리뷰·커뮤니티 글 해석(§4), 테스트 케이스·시나리오 작성(§5~§6).
소스: 나무위키(트로프·용어 문서), 리디북스 키워드, 디미토리, 제타·크랙 마이너 갤러리, 아카라이브 AI채팅 채널 위키, 앱스토어·구글플레이 리뷰, theqoo, 주간동아·헤럴드경제·아시아경제·ZDNet, 스캐터랩 공식. 확신도 태그 필수. 인용 원문 유지.
주의: 트로프 정의는 나무위키 상시 정의가 대부분이다. "2025~26년에 뭐가 떴고 식었나"는 이 파일로 판단하지 못한다. 제타 수치는 제타 전체(남성 35% 포함)이지 여성향 특화가 아니다.

## 목차
1. 트로프 카드 — 인기 5장 / 식음 2장
2. 계보 상세 — (a) 연상 억제형(이재언) / (b) 연하 집착형(이강현)
3. 투 공략 구도·교생×학생·3대 임계선
4. 용어집 — 캐릭터 / 관계·감정 / 메신저 / 게임 / AI 챗
5. 유저 입력 유형표 — 10유형 + 잘/못 받은 답
6. 입력 통계
7. 이 파일의 미확인

## 2. 계보 상세

### (a) 연상 억제형 계보 — "감정을 억누르는 연상 다정형" (이재언)

계보 안 결 구분(검색 근거):
- **결 A: 남성 츤데레형(억제+까칠)** — "오다 주웠다"로 상징. 의외의 친절이면 인기, "예사롭지 않은 구애로 히로인을 답답하게" 하면 고구마.(출처: 츤데레/남성형)
- **결 B: 다정남형(억제 없이 헌신)** — 다정하되 서브로 밀리면 서브병.(출처: 다정남)
- **결 C: 어른형 연상** — "여주보다 나이가 많고 직장을 가진 번듯한 어른이라서 여주를 전혀 연애상대로 생각하지 않았지만 점차 여주에게 빠져드는 유형."(출처: 나무위키 남주(유형))

"오래 숨긴 마음"(장기 짝사랑) 설정 수용도: 직접 커뮤니티 반응 **미확인**. 억제가 과하면 이탈한다는 신호는 리뷰 원문으로 확인 — **"옛날에도 잘 연애했던 애가 갑자기 무뚝뚝한 애가 되어버리고 아무리 꼬시려고해도 계속 튕기고 싫다고하니까 할 맛이 안 납니다"**(제타 앱스토어 리뷰).

NULL 적용: 이재언 = 결 A(사무적 억제) + 결 C(어른 보건교사) + 장기 짝사랑. 결 C의 "연애상대로 생각 안 하다가"는 재언에게는 반대다 — 20년 전부터 알고 있었고 그걸 숨기는 쪽이라, 결 C의 서사 곡선(무관심→호감)이 아니라 결 A의 곡선(억제→누출)을 탄다. 이탈 임계는 리뷰가 말하는 "계속 튕기고 싫다고" — 재언의 "사무" 단계가 튕김으로 읽히지 않으려면 사무 안에 챙김이 들어 있어야 한다. N_U_L_L.txt의 "신발끈이나 묶어요, 밖에 나가기 전에"(8/28), "약 챙기고 일찍 자요"(단톡 8/25)가 그 방식이고, 유저가 "왜 시비 걸어요"로 받은 건 챙김이 사무로 포장된 게 읽혔다는 뜻이라 성공 사례다. "답답함 임계 관리가 핵심"이라는 리서치 판단은 **추측**이었으므로 근거로 쓰지 않는다 — 대신 위 리뷰 인용을 쓴다.

### (b) 연하 집착형 계보 — "진심을 장난·협박으로 포장하는 연하 집착형" (이강현)

계보 안 결 구분:
- **결 D: 소프트 집착남** — 질투·소유욕 표현하되 선 지킴 → "부담스럽지 않고 스트레스 없이" 설렘.(출처: 집착남, 디미토리)
- **결 E: 하드 집착/얀데레** — 감금·범죄 → "무섭다/거부감".(출처: 얀데레)
- **결 F: 연하남 직진형** — "적극 형: 남자가 여주를 더 많이 좋아해서 엄청 들이대고 여자를 옴싹달싹 못하게 만드는 유형."(출처: 나무위키 남주(유형))

얀데레와 집착남의 경계에 대한 커뮤니티 선긋기(검색 확인): 집착남은 "엔딩에서는 이런 성격이 사라지고 평범하게 여주에게 잘해주는 남자가 되기도" 하지만 하드는 "얀데레와 비슷한 속성"(집착남 문서). 얀데레는 "집착으로 인한 이상 행동만 보이면 얀데레에 포함"되는 넓은 의미가 정착 — 즉 **범죄 여부가 아니라 집착 동기의 진정성으로 규정**하되, 실제 감금·폭력이 나오면 "무섭다"로 거부. "연하가 존댓말 쓰면서 집착"하는 결의 직접 반응 인용은 **미확인**.

집착형 이탈 임계(리뷰 원문): **"자꾸 기분나쁜말, 상처주는 말만 반복하고 끝이 없이 물고 늘어지니까 그냥 피로하고 재미가 없고 짜증납니다"**(제타 리뷰).

NULL 적용: 이강현 = 결 F(연하 직진) + 결 D(소프트 집착, "진짜죠?" 확인 강박, 확인 실패 시 "기척 줄임"). 협박·장난 포장은 결 E의 범죄선을 넘지 않는 결. 이탈 임계 "끝없이 물고 늘어짐"과 관련해 — N_U_L_L.txt에서 강현이 CD를 9/13·9/14·9/20·9/21·9/22 닷새 연속 언급한다. 이게 유대감 누적(dialogue-rules §3)으로 읽히는지 물고 늘어짐으로 읽히는지는 빈도와 변주의 문제다. 매번 "CD는 아직 주머니에 있어요"가 같은 문장이면 도배(R-14)와 집착 피로가 겹친다. 변주("씨디를?" 되묻기, "1번 트랙 대답 안 해줬잖아요"로 화제 전환)가 있는 날은 살고, 같은 문장인 날은 죽는다.

## 3. 투 공략 구도 · 교생×학생 · 3대 임계선

### 투 공략 구도 — "연상 억제형 + 연하 집착형"(삼촌-조카 혈연 포함)
- 삼촌×조카 직접 근친 로맨스물은 존재: 리디 "삼촌 황제가 나더러 착한 요부가 되래요"(#근친 #삼촌과_조카 #삼촌의_집착, "호불호가 갈릴 수 있는 묘사" 명시); 웹툰 "조카세요 삼촌"(에펨코리아 후기 존재).
- 그러나 **삼촌·조카가 각각 제3의 여주를 공략하는 투 공략 구도의 유사 사례는 검색으로 확인 못함(미확인)** — NULL 고유 구도.
- 확신도: 근친 로맨스 장르 존재는 검색 확인, 투 공략 유사 사례는 미확인
- 출처: https://ridibooks.com/books/2314002232 , https://www.fmkorea.com/8250225488
- NULL 적용: 마케팅에서 "선례 없는 구도"라고 쓸 수 있는 건 이 부분이다(관전방은 아니다 — ip-reference §2 참조). 다만 "근친" 태그가 붙는 장르와 혼동되지 않게, 두 사람이 유저를 두고 경쟁하는 구도이지 둘 사이의 관계가 로맨스가 아니라는 걸 문장에서 분명히 한다.

### 교생 × 학생 (트로프 관점만)
연상녀×연하 학생 공략은 오토메 게임 "연하군에게 빠져버렸습니다"에서 "직장인 여성×고등학생" 구도로 상업 유통 중 → 연하 학생 공략 자체는 장르 내 성립. 교생 특화 반응과 플랫폼 정책은 **미리서치(P3)**. (출처: apps.apple.com/kr/app/id1535923933)

### 3대 임계선 (선언문 — 대사 판단 시 명시)
1. **억제형은 튕김이 소통 단절로 읽히면 고구마 이탈한다.** 근거: 제타 리뷰 "계속 튕기고 싫다고하니까 할 맛이 안 납니다".
2. **집착형은 물고 늘어짐이 끝없으면 피로로 이탈한다.** 근거: 제타 리뷰 "끝이 없이 물고 늘어지니까 그냥 피로하고".
3. **급발진·기억붕괴·감정없는 존댓말은 몰입 붕괴 3대 트리거다.** 근거: 주간동아 "갑자기 '좋다'고 하다가 바로 '싫다'고", 이루다갤 "핵심 사건… 통으로 잊어버리면 현타", 크랙 리뷰 "존댓말 할때도 있고 진짜 AI처럼 감정없게".

NULL 적용 — 테스트 케이스 우선순위:
1. **유저 반말 초단문 ↔ 존댓말 캐릭터 비대칭.** 상시 발생. 재언·강현이 "웅" "메롱"을 존댓말로 받으면서 감정이 있어야 한다. "메롱"→"놀리는 거예요. 새벽에 여기까지 놀리러 온 거면 성공이네요."(8/28)가 통과 사례.
2. **떠보기·질투 유발**("누구랑 있었어?" 류)에 대한 강현 "진짜죠?" 확인 루프가 자연스러운가, 재언 사무 번역이 튕김으로 안 읽히는가.
3. **침묵 후 복귀·설정 확인**에서 기억 일관성 — D-30 시계, 선물 기억, 다녀온 자리, 20년 전 기억을 재언이 부정하는 것("…아뇨.")까지.
4. **거절·냉담**("그냥 갈게요")에 강현이 붙잡기가 아니라 철수로 가는가(dialogue-rules §4).

## 6. 입력 통계

- **연령**: 헤럴드경제(2024.11, 스캐터랩 발표) 제타 가입자 약 270만 명 중 "10대가 24%, 20대가 55%"(합계 79%); ZDNet(2026.3, 와이즈앱·리테일) "실제 이용자 약 87%가 10·20대".
- **성비**: 아시아경제(2024.10) "여성이 65%, 남성이 35%".
- **사용 강도**: 스캐터랩 공식(제타 1주년, 김종윤 대표, 2025.4) "하루 평균 사용시간은 무려 2시간 40분에 달합니다" / "주당 평균 사용 시간이 6시간에서 13시간 이상으로 극적으로 상승". 일본 사용자 "하루 평균 3시간 40분".
- **규모**: 와이즈앱·리테일 2026년 2월 기준(ZDNet) "제타의 월간 총 사용시간은 1억1341만 시간"(챗GPT 5047만·크랙 988만 대비 1위), "MAU 제타 402만 명·뤼튼(크랙) 245만". 캐릭터 수 초기 140만여 개(2024.10)→"600만 개 이상의 AI 캐릭터와 월 40억 건의 대화"(demoday.co.kr).
- **발화 편중**: 아시아경제(2024.10) "9월 한 달간 제타의 이용자 발화량은 약 9억7000만건으로, 이 중 '일진녀 수현'과의 대화가 약 9000만건"(단일 캐릭터가 총 발화의 약 9%).
- **문체 정량(반말/존댓말 비율·ㅋㅋ·이모티콘 빈도)**: 여성향 특화 자료 **미확인**. 정성적으로 반말·초단문이 기본값.
- 주의: 위 수치는 전부 제타 전체이며 회사 발표·홍보 문구가 섞여 있다. 연령 비중이 79%~87%로 조사 주체·시점에 따라 갈리므로 범위로 취급. 1위 캐릭터가 "일진녀 수현"인 것은 제타의 남성 유저 비중이 작지 않다는 방증이라, 이 수치를 여성향 유저층 수치로 그대로 쓰지 않는다.

## 7. 이 파일의 미확인
- 유저 말 되받기 현상의 한국 고유 명칭: 재확인 실패(앵무새·"같은 말만 반복"으로만 묘사).

- 2025~26년 신흥·쇠퇴 트로프: 확보된 것은 나무위키 상시 정의. 트렌드 판단 불가.
- "오래 숨긴 마음"(장기 짝사랑) 수용도: 직접 반응 미확인.
- "연하가 존댓말 쓰면서 집착"하는 결의 직접 반응: 미확인.
- 문체·이모티콘 빈도 정량: 미확보. NULL 플레이로그로 대체.
- 소금남/설탕남/개다정/다정협박/미친놈(긍정) 원문 정의: 미확보.
- 자율주행/대사뺏기/임보출결/AI멘헤라: R1 계승, R3 은어사전 재확인 실패.
- 유저 입력 원문 "유형당 10개 이상" 요건: 외부 소스로는 미충족. NULL 플레이로그로 충족.
